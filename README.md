# Learning

A personal learning repository for software engineering fundamentals, data
structures and algorithms, C#/.NET, and system design. It combines progressive
roadmaps and concept guides with small JavaScript and TypeScript practice
solutions.

## Contents

- [Complete C# and .NET Learning Roadmap](C%23%20and%20.NET/Complete-CSharp-DotNet-Roadmap.md) - a progression from setup and C# fundamentals through ASP.NET Core, data access, testing, security, deployment, and specialization.
- [Phase 0-1 C# Fundamentals Guide](C%23%20and%20.NET/Phase-0-1-CSharp-Language-Fundamentals-Guide.md) - detailed explanations, examples, and practice for environment setup and programming fundamentals.

## Suggested Study Workflow

1. Choose one track and follow its roadmap in order; use the checklists to track
   progress.
2. Read the related concept guide when a topic needs more explanation.
3. Implement or work through examples yourself, then compare approaches and
   consider time and space complexity where applicable.
4. Keep notes on mistakes, questions, and concepts to revisit.
5. Return to earlier topics regularly instead of treating a checklist as a
   substitute for practice.

## Working with the Examples

The JavaScript and TypeScript files are small, independent exercises, not one
application with a repository-wide build or test command. Run or compile an
individual example with tools appropriate to its language and any platform
requirements of the problem. The `Patterns` folder includes a small
`package.json` for its development dependency; it does not define project
scripts.

The C#/.NET and system-design sections currently focus on learning roadmaps and
written guides rather than a shared executable project.
